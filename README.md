# MindfulSpace - MindCare Mental Wellness Companion

A fully responsive mental wellness web app offering guided breathing exercises, mood tracking, mindfulness meditations, and a private thought journal to support emotional health.

## 🔗 Live Demo

[https://kirillchacha.github.io/drmilbourne/mindfulspace.html](https://kirillchacha.github.io/drmilbourne/mindfulspace.html)

## ✨ Features

- **Breathing practice** - guided exercises with customizable intervals (3–6 seconds) and session lengths (3–10 minutes)
- **Mood tracking** - log emotional states (calm, overwhelmed, angry, happy, tired, anxious) to monitor your emotional journey
- **Mindfulness practices** - multiple 10-minute guided body scan meditation sessions
- **Thought journal** - a private, secure space to write and save personal entries
- **Ambient sounds** - instrumental audio tracks to enhance meditation and focus
- **Motivational quotes** - rotating inspirational messages throughout the experience
- **Theme customization** - Light, Dark, and Pastel modes
- **Share Progress** - option to share wellness progress
- **Audio player** - built-in playback controls for ambient sound tracks
- **Fully responsive design** - optimized layout for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** - semantic markup for structure and SEO
- **CSS** - custom styling for layout, typography, theming, and responsiveness
- **JavaScript** - breathing timer logic, mood tracking, and interactive UI behavior
- **Audio assets** - ambient sound and music tracks for the meditation experience
